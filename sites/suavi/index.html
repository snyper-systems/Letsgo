Waar staan onze gegevens?

Binnen de Europese Unie. Alles wat een agent leest of maakt, blijft in de EU.

Kan de agent zelf iets versturen?

Nee. Elke mail, offerte of factuur wacht op de goedkeuring van iemand van je team.

Met wie werken we samen?

Rechtstreeks met de ontwikkelaar die je oplossing bouwt. Er zit geen accountmanager tussen.

Wie houdt de software draaiende?

Suavi. We leveren werkende software en blijven die daarna beheren.

Bouwen jullie ook websites?

Ja. Naast procesautomatisering en AI-agents bouwen we websites op maat.

Wat kost een agent?

Prijs op aanvraag: elke oplossing is maatwerk voor jouw taken.
